**Description:** This repo contains miscellaneous resources for accessing Google Earth Engine (GEE), *principally via the JavaScript-based [Code Editor](https://code.earthengine.google.com)*. This repo was initially developed for the **July 2025** NASA EarthData [webinar](https://www.earthdata.nasa.gov/events/fundamentals-use-hyperspectral-thermal-nasa-earth-observations) on hyperspectral and thermal Earth observation 🛰️🌎 data, where I and colleagues demonstrated the use of GEE for analyzing hyperspectral data. The information presented was later updated for the **August 2025** [AmeriGEO Week training webinar on PACE](https://youtu.be/nOXNXBQR3cw?t=8142), where I and colleagues also highlighted how PACE OCI hyperspectral data can be analyzed using GEE, particularly via the [PACE OCI Toolkit](https://github.com/BzGEO/PACE_OCI_Toolkit). This document has just been updated following the recent **April 2026** changes to GEE's compute resources.

## Accessing GEE

> [!IMPORTANT]
> **HOW** do I get access GEE?

1. **Register** for Google Earth Engine (GEE) if you don't already have an account: https://earthengine.google.com/signup/.
2. **Set up a Google Cloud project** in the GEE Code Editor: https://code.earthengine.google.com. (*You will be prompted to register an existing cloud project or to set up a new one.*) For a detailed walk-through of how to set up a Google Cloud project for GEE, please see the [**Tutorials**](https://github.com/BzGEO/GEE_resources#tutorials) section ⬇️.

![](https://github.com/BzGEO/GEE_resources/blob/main/_graphics/gee_cloud_project_registration_screen.png)

3. *Optional:* **Add a sample GEE code repository**, like the HLS examples repo (https://bit.ly/gee_repo_hls) or the PACE OCI 👨‍💻 repo (https://bit.ly/gee_repo_pace_oci).

![](https://github.com/BzGEO/GEE_resources/blob/main/_graphics/gee_add_pace_oci_repo.png)

## Data resources

> [!IMPORTANT]
> **WHERE** can I access data for viewing / analyzing / processing in GEE?

1. See the official GEE **Data Catalog** (*maintained by Google*): https://developers.google.com/earth-engine/datasets.
2. See the **Community Data Catalog** (*maintained by the community*): https://gee-community-catalog.org.
